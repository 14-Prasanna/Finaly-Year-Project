## ✨ Key Features

- **Real-Time Threat Prediction**: Analyzes 15 network flow metrics (like rate, duration, flag counts) to classify traffic instantly.
- **High-Accuracy ML Engine**: Powered by a pre-trained XGBoost model built on the CICIDS2017 dataset (>98% accuracy).
- **Interactive Dashboards**: Features an SVG speedometer risk gauge (0–100) and interactive feature bar charts.
- **AI Security Assistant**: Integrates Google Gemini 2.5 Flash for contextual threat mitigation and a cybersecurity Q&A chatbot.
- **Automated Reporting**: Download `.txt` intrusion reports or send them directly via SMTP email.
- **Comprehensive Logging**: Dual-layer Python logging (colored console output + rotating `.log` files).
- **Automated Testing Suite**: Full `pytest` integration with rich HTML test reports via Allure.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js** (v16+)
- **Python** (3.8+)
- **Google Gemini API Key** (for AI recommendations)
- **Gmail Account** with an [App Password](https://support.google.com/accounts/answer/185833) (for email reports)

### 1. Backend Setup

```bash
cd backend
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Mac/Linux
pip install -r requirements.txt
```

Create a `backend/.env` file with your credentials:
```env
GEMINI_API_KEY=your_google_gemini_api_key
SECRET_KEY=a_secure_random_string
EMAIL_SENDER=your_email@gmail.com
EMAIL_PASSWORD=your_gmail_app_password
```

Start the Flask server:
```bash
python app.py
```
> The backend runs on `http://127.0.0.1:5000`

### 2. Frontend Setup

In a new terminal:
```bash
cd frontend
npm install
npm start
```
> The React app will open at `http://localhost:3000`

## 📖 Usage & Dashboard

1. **Register & Login**: Create a new user account to access the dashboard.
2. **Submit Traffic Metrics**: Enter network parameters into the dashboard form. *Tip: Check `backend/data/sample_data.txt` for pre-configured payloads representing High Risk (DDoS), Medium Risk (Port Scan), and Normal traffic.*
3. **Analyze Results**:
   - View the 0–100 risk score on the SVG gauge.
   - Read the AI-generated mitigation steps specific to the detected attack.
   - Identify abnormal parameters via the Risk Factors analysis.
4. **Generate Reports**: Use the top-right menu to download a `.txt` report or email it directly to your registered address.

## 🧪 Testing & Quality Assurance

CyberShield includes a robust testing infrastructure covering authentication, ML prediction, input validation, and report generation.

### Run the Test Suite
```bash
cd backend
python scripts/run_tests.py
```
This script will:
1. Execute all 11 tests using a headless Flask test client.
2. Generate an HTML report in `backend/reports/`.
3. Automatically build an interactive Allure dashboard (if the Allure CLI is installed).

### Test Coverage (11 Tests)
- **Health & Auth**: API pings, registration, valid/invalid logins.
- **Predictions**: Accurate classification of DDoS, Port Scans, and Benign traffic.
- **Validation**: Rejection of empty bodies and invalid content types.
- **Reporting**: Verification of generated `.txt` report contents.

## 🔐 Security Implementation

| Layer | Implementation Details |
|---|---|
| **Passwords** | Hashed using `werkzeug.security` (bcrypt). |
| **Sessions** | Server-side secure HTTP-only cookies (`flask-session`). |
| **Secrets** | Environment variables parsed via `python-dotenv`. |
| **Validation** | Strict JSON schema checks before ML model ingestion. |
| **CORS** | Restricted `flask-cors` configuration (only accepts `localhost:3000`). |
| **Email** | Encrypted SMTP via SSL (Port 465). |

## 📊 Dataset & ML Details

The XGBoost model was trained on the **CICIDS2017** dataset (Canadian Institute for Cybersecurity Intrusion Detection System).
- Features recognized: `Duration`, `Rate`, `Srate`, `fin_flag_number`, `Tot size`, `Protocol Type`, etc.
- Classes detected: Benign, DDoS (LOIT, HOIC, LOIC-UDP), DoS (Hulk, GoldenEye, Slowloris), Brute Force (FTP/SSH), Web Attacks (XSS, SQLi), Infiltration, Botnet, and Port Scan.

## 🔌 API Reference

| Method | Route | Description |
|---|---|---|
| `GET`  | `/ping` | Backend health check. |
| `POST` | `/register` | Create a new user (username, password, email). |

| `POST` | `/logout` | Destroy the active session. |

| `POST` | `/send_report_email`| Dispatch the analysis report via SMTP. |
