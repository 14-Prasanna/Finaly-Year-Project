================================================================
  FIELD REFERENCE GUIDE
================================================================

  flow_duration    Duration of the network flow in milliseconds
  Header_Length    IP/TCP header length in bytes
  Protocol Type    IP protocol number (6=TCP, 17=UDP, 1=ICMP)
  Duration         Total connection duration in milliseconds
  Rate             Total packet rate (packets per second)
  Srate            Source-to-destination packet rate (pps)
  fin_flag_number  Count of TCP FIN flags observed in the flow
  Std              Standard deviation of packet inter-arrival time
  Tot size         Total payload size in bytes
  IAT              Mean inter-arrival time between packets (ms)
  Magnitue         Magnitude metric of flow (sqrt of src+dst bytes)
  Radius           Radius metric (std dev of src+dst bytes)
  Weight           Covariance weight metric of the flow
